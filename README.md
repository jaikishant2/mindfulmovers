# Mindful Movers Chess Club ♟️

Official website for **Mindful Movers Chess Club**, founded by **Coach P.S.Jaikishan** in Chennai, India. Offering premier in-person chess coaching in Chennai and live online coaching for students worldwide (India, USA, UAE, UK, Australia, and beyond).

🌐 **Live Demo & Features**:
- **Hero & Story**: Interactive SVG chessboard, academy mission, and Coach Jaikishan profile.
- **Why Chess (Benefits)**: Problem-solving, memory & focus, strategic thinking, resilience.
- **Coaching Batches**: Beginner, Intermediate, and Advanced batches with comprehensive training curriculums.
- **Hall of Fame**: Student champions, state-level tournament winners, and trophy showcases.
- **Interactive Puzzle**: Weekly checkmate puzzle with dynamic chessboard display.
- **Enrollment / WhatsApp Integration**: Direct demo class booking sent directly to Coach Jaikishan (+91 883 851 2840).

## 🚀 Running Locally
You can view the website directly by opening `index.html` in any modern web browser or run the included PowerShell dev server:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then navigate to `http://localhost:8080/`.
